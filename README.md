# Post Your Thought

A social media platform built with React, TypeScript, and Vite. Authenticated users can set up their profile, post their thoughts, browse other users' profiles and posts, like posts, and scroll through an infinite-scrolling homepage feed.

## Tech Stack

- React 19 + TypeScript
- Vite
- React Router
- TanStack React Query
- Firebase (Auth, Firestore, Storage)
- Zod for form validation
- CSS Modules

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build locally
